# Caja de tienda

Proyecto personal en Python que simula una caja de tienda.

## Qué hace

- Guarda productos con precio y cantidad.
- Calcula subtotales.
- Calcula el total de compra.
- Aplica un descuento si el total supera cierto monto.

## Conceptos practicados

- Listas
- Diccionarios
- Ciclos
- Condicionales
- Operaciones matemáticas

## Cómo ejecutar

```bash
python caja_tienda.py
