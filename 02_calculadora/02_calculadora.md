# Calculadora en Python

Proyecto personal de práctica en Python que permite realizar operaciones básicas desde la consola.

## Qué hace

- Suma dos números.
- Resta dos números.
- Multiplica dos números.
- Divide dos números.
- Valida que el usuario ingrese números correctos.
- Evita errores al dividir entre cero.

## Conceptos practicados

- Entrada de datos con `input`
- Conversión de tipos con `float`
- Condicionales `if`, `elif`, `else`
- Ciclo `while`
- Manejo de errores con `try` y `except`
- Operaciones matemáticas básicas

## Cómo ejecutar

```bash
python calculadora.py
